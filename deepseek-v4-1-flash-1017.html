The short answer

DeepSeek-V4.1-Flash-1017 is the Flash-tier checkpoint released on 17 October 2026. DeepSeek calls it a minor update to V4.1-Flash, but most of the agentic and coding rows on the model card move by double digits (Terminal-Bench 4.0 from 31.2 to 42.3, ProgramBench from 20.3 to 29.1), while the vendor also reports shorter task times and shorter outputs. In other words: stronger and cheaper to run, not just a higher score. The weights stay MIT-licensed, the API model name is still deepseek-flash, and the price list did not change.

  • Running agents, terminal or repo-scale work: on this table the 1017 checkpoint has the top score among the five listed models on six rows — Terminal-Bench 4.0, DeepSWE v1.1, ProgramBench, Automation-Bench, Agents' Last Exam and Apex Bench.
  • Pure reasoning and general knowledge: Opus 5 still leads on HLE (56.3 vs 42.6), NL2Repo-Bench (75.3 vs 68.2) and some vision rows, and GPT-5.6 Sol is higher on ZeroBench-main.
  • Cheapest unit cost with 1M context and image input: that is exactly this model's slot — $0.15 / $0.60 per million tokens off-peak on the official API, down to $0.10 / $0.50 on aggregator routes.

Three things that actually changed besides the scores

  • Faster tasks, shorter outputs: DeepSeek's announcement calls it a Pareto improvement in performance and cost — the same task now finishes sooner and writes less, so it burns fewer tokens. For a production agent pipeline that matters more than a leaderboard row.
  • Search and Fetch APIs are open to everyone: billed per successful request at $0.75 per 1,000 calls for each endpoint. Server-side tool calls through DeepSeek Harness, Claude Code and Codex are currently free, with billing starting at 00:00 Beijing time on 1 November 2026 (16:00 UTC on 31 October).
  • Tighter agent-harness fit: DeepSeek names DeepSeek Harness, Tencent CodeBuddy and WorkBuddy, and recommends upgrading DeepSeek Harness to v0.2.1-rc.1 or later for the best experience.

💰 Official API Pricing and How to Call It

The 1017 checkpoint is served under the same API model name, deepseek-flash, at the same list price as the previous Flash version. The table below is taken from the official price list, per 1M tokens.

Time-of-day rulePeak = Mon-Fri 01:00-04:00 and 06:00-10:00 UTC (excluding Chinese public holidays); everything else, including weekends, is half-price off-peak.
 Source: DeepSeek API docs, Models & Pricing (read 2026-10-17). Search and Fetch are billed separately per request: $0.75 per 1,000 successful calls.

Worked example: 1M input (cache miss) + 250K output

  • Off-peak: $0.15 + 0.25 x $0.60 = $0.30
  • Peak: $0.30 + 0.25 x $1.20 = $0.60
  • All input on cache hits (an agent re-reading the same long context): $0.003 + 0.25 x $0.60 = about $0.153
  • The same job on deepseek-v4-pro (off-peak $0.66 / $1.98) is about $1.16 — roughly 3.9x this Flash checkpoint.

How to call it (from the official price list)

  • Use the model name deepseek-flash. The legacy names deepseek-v4-flash and deepseek-v4-flash-vision-exp are still accepted, but those models are retired: requests are served by V4.1-Flash-1017 and billed at the Flash price.
  • 1M-token context, maximum output listed as 384K, switchable thinking / non-thinking modes (thinking is the default), tool calls, JSON output, the Responses API and the Anthropic API format, with a concurrency limit of 2,500.
  • Image input is Flash-only here: V4-Pro does not take images. If your pipeline involves screenshots or rendered PDF pages, that alone pins you to the Flash tier.

🧩 Weights and Self-Hosting: What to Watch

The weights are still MIT-licensed and the repository carries inference and encoding instructions, but there is one trap this time: no Jinja chat template.

📦

Where the weights are

Published on Hugging Face (deepseek-ai/DeepSeek-V4.1-Flash-1017) and ModelScope under the MIT licence, tagged FP8 8-bit and image-text-to-text. Within hours of release the HF repo had 680 likes and 11 open discussions.

⚠️

No Jinja chat template

This release ships no Jinja-format chat template. The repository's encoding folder contains a self-contained Python reference implementation covering multi-turn conversations, tool calling, thinking mode, numeric reasoning effort, mid-conversation system messages and interleaved image content.

🦀

Use deepseek-recipe in production

DeepSeek also publishes deepseek-recipe, a set of Rust libraries with Python bindings: it converts Messages, Chat Completions and Responses API requests into the Conversation format, encodes them into prompts or token IDs, and parses output back into complete or streamed responses. Model inference, tool execution and HTTP transport are left to the caller.

🎛️

Recommended sampling settings

The model card's recommended defaults: temperature 1.0, top_p 1.0, a 1M-token context window, and max_tokens of at least 256K. That is a minimum output budget, not a target length to fill.

If you want to serve this model on your own cluster, there is a second path: on 20 October 2026 DeepSeek open-sourced its production engine, DeepInfer (Apache 2.0). It supports V4.1-Flash only, runs on SM100 and Ascend 950 only, and ships without the KV cache, P/D orchestration or the load balancing — whether it fits depends on whether you already own those cards.

❓ FAQ

What does the 1017 in DeepSeek-V4.1-Flash-1017 mean?

It is the release date encoded in the model name: 17 October 2026. DeepSeek describes it as a minor update to DeepSeek-V4.1-Flash rather than a new generation, but the model card shows double-digit gains on several agentic benchmarks, for example Terminal-Bench 4.0 rising from 31.2 to 42.3.

What is the API model name for DeepSeek-V4.1-Flash-1017?

On DeepSeek's own API it is deepseek-flash; there is no dated model ID to call. The legacy names deepseek-v4-flash and deepseek-v4-flash-vision-exp are still accepted, but those models have been retired: the requests are served by DeepSeek-V4.1-Flash-1017 and billed at the Flash price. OpenRouter lists the same checkpoint as deepseek/deepseek-v4.1-flash-1017.

How much does DeepSeek-V4.1-Flash-1017 cost?

Official DeepSeek list prices per 1M tokens: cache-hit input $0.003 off-peak and $0.006 at peak, cache-miss input $0.15 off-peak and $0.30 at peak, output $0.60 off-peak and $1.20 at peak. Off-peak is half of peak; peak hours are 01:00-04:00 and 06:00-10:00 UTC, Monday to Friday, excluding Chinese public holidays. Third-party routes on OpenRouter start at $0.10 input and $0.50 output per 1M tokens.

Is DeepSeek-V4.1-Flash-1017 open source, and can I self-host it?

Yes. The weights are published under the MIT licence on Hugging Face and ModelScope. Note that this release ships no Jinja-format chat template: DeepSeek provides a Python reference encoder in the repository encoding folder and a Rust toolkit called deepseek-recipe for production prompt formatting. Recommended sampling settings are temperature 1.0, top_p 1.0 and at least 256K max output tokens.

Does DeepSeek-V4.1-Flash-1017 support images and tool calls?

Yes to both. The checkpoint is tagged image-text-to-text, and DeepSeek's pricing table lists vision support on Flash, while V4-Pro does not take images. Tool calls, JSON output, the Responses API and the Anthropic API format are all listed as supported, with a concurrency limit of 2,500.
